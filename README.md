<h1 align="center">Assisi Connect</h1>

<p align="center">
  A modern parent portal for Assisi Vidyaniketan Public School.<br>
  <a href="https://assisi.ac.in/">🌐 assisi.ac.in</a>
</p>

---

Assisi Connect is a mobile application designed to replace Entab's CampusCare with a cleaner, faster, and more intuitive experience for parents of Assisians.

## Goals

- Modern UI/UX
- Faster navigation
- Better organization
- Useful features
- Consistent design language inspired by Assisi's colours and identity

## Current Status

🚧 In Development
